# Mac 構成 & 価格カタログ

Mac の機種とスペックを選ぶと価格が表示され、複数の構成を一覧で見比べられるサイトです。
Apple 公式サイトのような構成ビルダーの使い心地に、複数構成の横並び比較と差分表示を加えています。

## 使い方

`index.html` をダブルクリックしてブラウザで開くだけです（サーバー不要）。

ターミナルからなら:

```sh
open index.html
```

## 機能

1. 機種を選ぶ — MacBook Air / Pro、iMac、Mac mini / Studio / Pro をカードから選択
2. スペックを選ぶ — チップ・メモリ・ストレージを選ぶとリアルタイムで合計価格を表示
3. 構成を見比べる — 「比較に追加」で複数構成を表に並べ、最安構成をハイライト表示
4. 差分を見る — 一番左（構成1）を基準に、各構成の CPU / GPU コア数・メモリ・ストレージ・価格の差分を自動表示。スペックを揃えれば差分が消え、違う部分だけが浮かび上がります

## 収録ラインナップ（2026年6月時点）

### 現行モデル

| 機種 | チップ |
| --- | --- |
| MacBook Air 13" / 15" | M5 |
| MacBook Pro 14" | M5 / M5 Pro / M5 Max |
| MacBook Pro 16" | M5 Pro / M5 Max |
| iMac 24" | M4 |
| Mac mini | M4 / M4 Pro |
| Mac Studio | M4 Max / M3 Ultra |
| Mac Pro | M2 Ultra |

### 前世代モデル（世代間比較用・「前モデル」バッジ付き）

| 機種 | チップ | 世代 |
| --- | --- | --- |
| MacBook Air 13" / 15" | M4 | 2025年モデル |
| MacBook Pro 14" | M4 / M4 Pro / M4 Max | 2024年モデル |
| iMac 24" | M3 | 2023年モデル |
| Mac mini | M2 / M2 Pro | 2023年モデル |
| Mac Studio | M2 Max / M2 Ultra | 2023年モデル |

現行（例: MacBook Air M5）と前世代（M4）を両方「比較に追加」すれば、同一機種の世代間比較ができます。
比較表の「世代 / 発売」行で現行・前モデルを見分けられます。

## ファイル構成

- `index.html` — ページ本体
- `styles.css` — Apple 風スタイル
- `data.js` — 機種・チップ・価格データ（ここを編集すれば価格を更新できます）
- `app.js` — 構成ビルダーと比較表のロジック

## 価格について

- ベース価格は 2026年6月25日の価格改定を反映した Apple 公式の開始価格に基づく参考値です。
- メモリ・ストレージ等のアップグレード加算額は、Apple の一般的な価格体系に基づく概算値です。
- 「前モデル」の価格は各機種の発売時の定価を基準にした参考値です（現行は最新価格のため、世代間の金額差は目安）。
- 正確な価格・在庫・最新モデルは [Apple 公式サイト](https://www.apple.com/jp/) でご確認ください。

## データの更新（メンテナンス）

価格やモデルの情報は `data.js` の 1 ファイルに集約しています。価格改定や新モデルが出たときは、
ここを編集して `index.html` を再読み込みするだけで反映されます。

具体的な手順（価格の更新、構成の追加、新機種・新世代の追加、確認方法、つまずきやすい点）は
[MAINTENANCE.md](MAINTENANCE.md) にまとめています。
